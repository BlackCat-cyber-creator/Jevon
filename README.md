# Cap'n J's Treasure Map

Ahoy there! Welcome to **Cap'n J's Treasure Map**, the personal portfolio of Jevon Naldo Yoshield.

This repository houses a creative 3D web experience that acts as a digital expedition through my skills, projects, and professional journey as a Full-Stack Architect, Creative 3D Web Developer, and Systems & AI Engineer.

## 🏴‍☠️ About the Project

The portfolio is designed as an immersive, pirate-themed journey. It leverages modern web technologies to deliver interactive 3D elements, smooth animations, and a performant user experience.

Explore the different sections:
*   **Hero Deck**: A welcoming landing area.
*   **A Seadog's Manifesto (About)**: My professional profile and engineering pillars.
*   **Arsenal of the High Seas (Technologies)**: Interactive 3D orbs showcasing the tools and technologies I use.
*   **Grand Heists & Booty (Projects)**: Featured full-stack applications and projects I've shipped.
*   **Captain's Quarters (Contact)**: Reach out via a digital message in a bottle or find me on socials.

## 🛠️ Technologies Used

This project is built with a robust and modern tech stack:

*   **React (v18)**: For building the component-based user interface.
*   **Three.js & React Three Fiber (@react-three/fiber, @react-three/drei)**: Powering the interactive 3D elements and canvas backgrounds.
*   **Tailwind CSS**: For rapid, utility-first styling and responsive design.
*   **Framer Motion**: Delivering fluid, declarative animations and transitions.
*   **Vite**: The blazing-fast frontend tooling and bundler.
*   **TypeScript**: Ensuring type safety and better developer experience.
*   **Lucide React**: For scalable vector icons.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

*   Node.js (v16 or higher recommended)
*   npm (or yarn/pnpm)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/BlackCat-cyber-creator/portfolio-repo.git
    cd portfolio-repo
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to `http://localhost:5173` (or the port specified by Vite in your terminal) to view the portfolio.

## 📦 Scripts

*   `npm run dev`: Starts the Vite development server.
*   `npm run build`: Compiles TypeScript and builds the project for production.
*   `npm run preview`: Locally previews the production build.
*   `npm run lint`: Runs ESLint to check for code quality issues.
*   `npm run ts:check`: Runs the TypeScript compiler to check for type errors without emitting files.
